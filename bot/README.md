# 포켓 상담·신호 텔레그램 봇 (개발팀 아이티)

## 구성
- `bot.py`: 봇 본체 (상담, 무료체험, 승인·입금 확인 버튼, 기간 관리, 신호 전송, 현재 포지션 조회)
- `vba/FoketBot.bas`: Sean님 엑셀에 넣는 모듈 (CP949 저장, VBA 편집기에서 파일 가져오기). '봇' 시트 표를 10초마다 봇에 보내고, 포지션(C열)이 바뀌면 그 종목 회원에게 신호 전송
- `env.example`: 설정 예시 (서버에서 `.env`로 복사)
- `holidays.txt`: 신호 쉬는 날 (거래일 계산용)

## 흐름
1. 회원 /start → 언어 선택(8개) → 메뉴: 현재 포지션 보기, 무료체험, 요금, 결제, 내 현황
2. 무료체험: 이름 → 연락처 → 서비스(데일리/셀렉트) → 위험고지·약관 동의 → Sean님께 [승인][거절]
3. 승인 → 다음 거래일부터 10거래일. 8거래일째 종료·요금 안내, 끝나면 결제 안내
4. 결제: 계좌/해외 안내 → 회원이 "입금했습니다"+입금자명 → Sean님께 [입금 확인][미확인]
5. 입금 확인 → 다음 거래일부터 20거래일 (이용 중이면 끝난 다음 날부터 이어 붙임). 만료 3거래일 전 갱신 안내
6. 엑셀 '봇' 시트: 한 줄 = 한 종목. A 종목코드, B 종목명, C 포지션, D 진입가, E 현재가, F 평가손익, G 진입시간, H에 Y = 오늘 데일리 종목
   - 데일리 회원: H열 Y 종목(포켓이 매일 고른 해외 1 + 한국 1). 셀렉트 회원: 직접 고른 1종목. 메뉴 "서비스·종목 바꾸기"로 데일리↔셀렉트, 종목을 언제든 변경
   - 봇은 A열 코드로 종목을 알아보므로 30종목이든 줄 순서가 바뀌든 상관없음
7. 신호: C열 포지션이 바뀌면 엑셀 → `POST /signal` (sym=종목코드) → 그 종목을 받는 이용 중 회원에게만 (전달·저장 제한)
8. 현재 포지션: 엑셀 → `POST /position` (표 전체) → 회원이 버튼이나 "포지션" 글을 보내면 자기 종목 줄만 보여 줌. 5분 넘게 갱신 없으면 경고
9. 일반 질문은 AI가 회원 언어로 답변. 결제 문제·환불·제휴 등은 Sean님께 전달, Sean님이 그 메시지에 '답장'하면 회원에게 전달
10. 매일 07:00(KST) 기간 처리 + Sean님께 회원 현황 요약. Sean님 명령: /stats, /signal 내용, /position

## 설치 (홈페이지 EC2 서버에 같이 설치)
이 폴더는 홈페이지 배포 때 서버의 `/var/www/foket/bot` 에 같이 올라갑니다. 봇은 `/opt/foket-bot` 에 따로 설치되어 홈페이지 배포(`git clean`)와 섞이지 않습니다.
```
cd /var/www/foket/bot && sudo bash install.sh
```
- 처음 한 번 토큰·관리자 번호·API 키·입금 계좌를 묻고 `/opt/foket-bot/.env` 에만 저장합니다 (권한 600).
- EC2 보안 그룹에서 TCP 8080 인바운드를 열어야 엑셀이 신호를 보낼 수 있습니다.
- 봇 코드를 고친 뒤 다시 반영: 같은 명령을 한 번 더 실행 (설정은 유지).
- 상태 확인: `sudo systemctl status foket-bot`, 기록 보기: `sudo journalctl -u foket-bot -n 50`
