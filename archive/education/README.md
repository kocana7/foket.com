# ROF 교육 콘텐츠 보관 (2026-11-27)

네이버 카페를 당분간 쓰기 어려워 홈페이지에서 교육 콘텐츠를 내리고 여기에 보관합니다.
카페를 다시 쓸 수 있게 되면 아래 방법으로 되돌립니다. 이 폴더는 `public/` 밖에 있어 사이트에 노출되지 않습니다.

| 파일 | 원래 위치 | 되돌리는 방법 |
| --- | --- | --- |
| `edu-card.html` | `public/index.html` 서비스 섹션, `#idea-automation` 카드 바로 다음 | 그 자리에 그대로 붙여 넣기 |
| `faq-edu-items.js` | `public/js/faq-content.js` 의 `items` (위험·책임 섹션 바로 앞) | 파일 맨 위 주석 참고 |

그대로 남겨 둔 것 (되돌릴 때 따로 손볼 필요 없음)
- `public/index.html` 의 `.edu-*` CSS: 아이디어 자동화 카드가 같은 레이아웃을 씁니다.
- `public/index.html` 8개 언어 번역의 `edu.*` 키: 카드를 붙여 넣으면 바로 번역됩니다.
- `public/js/faq-content.js` 의 `catNames.edu` (카테고리 이름 8개 언어).
